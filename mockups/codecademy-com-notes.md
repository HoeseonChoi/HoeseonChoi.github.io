# codecademy-com — 특징 메모

**팔레트**: 네이비 `#10162F` 다크 배경 + 패널 `#1D2340`, 옐로우 `#FFD300` primary CTA·선택 칩, 링크 `#66C4FF`, 경고 `#DC5879`, 텍스트 white / `rgba(255,255,255,.65)` / `.45` 3단 위계.

**타이포**: Apercu → Space Grotesk + Noto Sans KR. 굵은(700) 타이틀 25px, 섹션 14px 볼드, 본문 13.5px — 한 패밀리를 웨이트로만 위계화하는 grotesque 단일 축.

**레이아웃**: 섹션 = 1px 보더의 다크 카드 안에 hairline 구분선으로 나뉜 행들(craft-do의 분리된 카드들과 대비되는 '한 덩이 패널' 구조). radius는 전반적으로 작게(버튼·칩 4px, 카드 8px), 간격 콤팩트.

**컴포넌트 시그니처**: 박시한 radius-4 버튼 + 하드 오프셋 섀도(`0 4px 0 #0A0D1C`, Gamut 특유의 flat-brutalist 결), 솔리드 D-day 뱃지(D-1 `#DC5879` / D-3 `#FFD300`), 스퀘어 스테퍼, 네이비-900 탭바 + 옐로우 액티브, 타이틀 아래 옐로우 언더바.

**분위기**: 대담하고 하이콘트라스트, 게이미피케이션된 학습 플랫폼 특유의 에너지.

**이 앱에 적용 시 장단점**: ① 옐로우 CTA와 솔리드 경고 뱃지의 대비가 강해 '스캔해서 추가'·'구매 필요' 같은 핵심 행동 유도에 효과적이고, 저조도(저녁 장보기·요리 중)에서 눈이 편하다. ② 4px 박시 컴포넌트는 작은 터치 타깃에서도 경계가 명확해 ± 스테퍼 조작이 안정적. ③ 단점: 다크 네이비 + 형광 포인트는 연령대가 넓은 가족 공용 앱에서 차갑고 '개발자 도구'스럽게 느껴질 수 있고, 파스텔 이모지 썸네일과 다크 배경의 톤 충돌을 계속 관리해야 한다.
