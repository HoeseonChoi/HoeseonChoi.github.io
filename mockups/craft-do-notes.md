# craft-do — 특징 메모

**팔레트**: 잉크 `#030302` + 오프화이트 배경 `#FBFBF8`, 헤어라인 보더 `#03030217`, 앰버 `#e9bd15` 포인트. 파스텔 태그 팔레트(`#f5e090`/`#79620a` 앰버, `#89b371` 그린, `#acc3ba` 틸, `#427e8a` 블루, `#bb433a` 레드)를 썸네일·D-day 칩·카운트 pill에 분산 적용.

**타이포**: 헤딩 세리프(Untitled Serif → Newsreader + Noto Serif KR, 28px, tracking -0.02em) — '우리집' 타이틀만 세리프로 두는 것이 Craft 시그니처. UI는 산스(Untitled Sans → Inter + Noto Sans KR), 12.5–14.5px, 500–600 웨이트 중심.

**레이아웃**: 넉넉한 여백과 hairline 보더의 floating 화이트 카드(radius 14–18px, 미세 섀도). 섹션 = 13px 볼드 라벨 + 파스텔 카운트 pill + 우측 텍스트 링크.

**컴포넌트 시그니처**: 블랙 pill primary 버튼 + outlined secondary, 파스텔 rounded-square에 이모지를 얹은 'doc icon' 썸네일, D-day pill 칩(D-1 pale red / D-3 pale teal), 미니멀 라인 탭바 + 액티브 탭 아래 앰버 도트.

**분위기**: 차분하고 에디토리얼한 "calm efficiency" — 노션/문서 도구 특유의 정돈된 종이 질감.

**이 앱에 적용 시 장단점**: ① 파스텔 컬러코딩이 식료품 카테고리·유통기한 구분과 자연스럽게 맞고, 세리프 타이틀이 '우리집'에 따뜻한 가족 톤을 준다. ② 낮은 채도·헤어라인 보더는 화면이 조용해 매일 반복 사용에 피로가 적다. ③ 단점: 대비가 낮아 '구매 필요/유통기한 임박' 같은 경고성 정보의 긴급감이 약하고, 넓은 여백 + 세리프는 정보 밀도를 낮춰 재고가 많은 가구에서는 스크롤이 길어진다.
