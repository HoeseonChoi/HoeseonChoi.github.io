# tokens-studio — 특징 메모

- **팔레트**: 소프트 오프화이트 `#f7f6f2` 배경 + 딥 인디고 잉크 `#251d5c` 본문/제목. 시안 `#11c8d5`가 dominant(Primary CTA·+버튼·탭 인디케이터), 핑크 `#fc79a4`(경고·0개·D-1), 퍼플 `#605ea7`(secondary·링크·D-2), 세이지 `#c6cdaa`(무채색 칩·D-4). 파스텔 × 하이콘트라스트 조합.
- **타이포**: 디스플레이는 Almarena 대신 Archivo 800/900(-1.3px 타이트 트래킹) — '우리집.' 같은 초볼드 기하 산세리프. 본문·버튼은 Lato(스펙 button 역할). 카운트·수량 숫자도 Archivo로 힘있게.
- **레이아웃/컴포넌트**: radius 0↔42 극단 — 카드 20~26px, 칩·검색·탭바는 완전 pill. 흰 카드 + 얕은 헤어라인 보더 + 긴 소프트 섀도(인디고 tint). 퀵액션은 floating glass card 위에 시안 그라디언트 solid 버튼. 상단에 회전+skew된 파스텔 등각 '캔디 블록' 3개를 띄워 tokens.studio 히어로의 플로팅 3D UI 시그니처 재현. 탭바는 화면 아래 뜨는 pill 바 + 시안 도트 인디케이터.
- **분위기**: 디벨로퍼 툴 랜딩의 쿨하고 세련된 SaaS 무드 — 장난기 없이 정돈된 파스텔.
- **이 앱에 적용 시**: 장) 저채도 배경+고대비 잉크라 한국어 해요체·숫자 가독성 우수, 섹션 카드 위계가 명확하고 시안 accent가 '스캔' CTA에 잘 먹힘. 단) 파스텔 경고색(핑크/세이지)은 유통기한 긴급도 위계가 약하게 읽힐 수 있고, 등각 3D 장식은 일일 반복 사용 앱엔 시각 노이즈·렌더 비용만 늘릴 여지. 전반적으로 '정돈된 프리미엄' 방향이라 가족 앱의 친근함보다 도구적 느낌이 강함.
